# پوشش پروژه نسبت به پروپوزال (`about.html`)

تاریخ: ۱۴۰۴/۰۶/۲۰ · پس از تکمیل شکاف‌های نرم‌افزاری

## خلاصه

| فاز پروپوزال | پوشش تقریبی | توضیح |
|---|---|---|
| فاز ۱ — وب‌سایت | ~۹۵٪ | کامل |
| فاز ۲ — پلتفرم ورزشکار | ~۹۰٪ | بازیابی رمز، کلاس، QR، پیشرفت تکمیل شد |
| فاز ۳ — باشگاه هوشمند (نرم‌افزار) | ~۷۵٪ | QR + API اثرانگشت + تاریخچه تراکم + لیدربورد |
| فاز ۳ — سخت‌افزار اثرانگشت | شبیه‌ساز/API | دستگاه فیزیکی لازم است |
| فاز ۴ — رشد و هوشمندی | ~۲۰٪ | CRM/retention هست؛ AI کامل نیست |

**پوشش نرم‌افزاری قابل‌ادعای فاز ۱–۳: حدود ۸۵٪**

## آنچه تازه تکمیل شد

- کد QR حضور ورزشکار + چک‌این پذیرش با کد
- گیشه عمومی `/kiosk/[slug]` (QR + شبیه‌ساز اثرانگشت)
- API دستگاه: `POST /api/kiosk/fingerprint` و `POST /api/kiosk/check-in`
- مدل `BiometricTemplate` (فقط شناسه قالب دستگاه)
- منبع حضور `FINGERPRINT`
- تاریخچه تراکم `OccupancySnapshot` + نمودار در صفحه شعبه
- کلاس‌های گروهی `/athlete/classes`
- ثبت اندازه‌گیری + جدول رتبه `/athlete/leaderboard`
- بازیابی رمز `/forgot-password` → `/reset-password`
- اعلان انقضای عضویت (دکمه ادمین + `/api/cron/membership-expiry`)

## آنچه هنوز کامل نیست (عمدی / فاز بعد)

- دستگاه فیزیکی اثرانگشت و SDK سازنده
- پیش‌بینی تراکم و تحلیل ساعتی پیشرفته
- SMS / Web Push / تلگرام
- اپ موبایل Native
- پرداخت هزینه جلسه تمرین شخصی
- CMS کامل ایجاد مقاله در ادمین
- دستیار AI گفت‌وگویی
- چالش ماهانه کامل گیمیفیکیشن
